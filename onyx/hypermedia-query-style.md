# Query style

How a Query block presents its results: a card grid, a compact list, or a table.


This document describes the **hypermedia-query-style** type — a Hypermedia Network blob schema. Its formal schema is attached (the `schemaDefinition` in this document's metadata), so the app can show it and create values of this type.

## Shape

Kind: `string`. One of: `Card`, `List`, `Table`.
