---
name: Bytes
summary: Raw binary data (a byte string).
---
The **bytes** type is raw binary data: a sequence of bytes that is not text. A public key and a signature are stored as bytes. It is a [primitive](./schema/primitive.md) of the [data model](./schema/data-model.md): the ready-made schema for one [kind](./schema/kind.md) of value. The type's formal schema is attached to this page as the `schemaDefinition` in its [metadata](./metadata.md). So the app can show the schema and create values of this type. <!-- id:eLT4he5Z -->
