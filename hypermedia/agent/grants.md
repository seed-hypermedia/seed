name: Grants
summary: "Grants are an agent's permissions: which callable tools it may use, whether it may publish signed content, and which MCP servers it may reach."
---
**grants**: an agent's permissions. They list the callable tools it may use (`search`, `query`, `attributes`, `web_search`, `execute`), whether it holds **publish** (signed public writing, see [write](./write.md)), and which [MCP servers](./mcp.md) are enabled. The verbs are never grants: they are always on. [Security](./security.md) and [tools](./tools.md) explain how grants are enforced. <!-- id:LJVrqOOs -->
