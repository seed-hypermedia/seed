---
name: Grants
summary: "Grants are an agent's permissions: which callable tools it may use, whether it may publish signed content, and which MCP servers it may reach."
---
**grants** — per-agent permissions: the callable set (`search`, `query`, `attributes`, `web_search`, `execute`), **publish** (signed public writing), and the enabled **MCP servers**. Verbs are never grants; they're always on. <!-- id:LJVrqOOs -->
