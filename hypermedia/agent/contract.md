**contract**: a tool's full model-facing spec, its description plus its input and output schemas. `read ~/tools/<name>` returns it. A wrong [call](./call.md) also returns it, and once it is in a thread the tool gets [promotion](./promotion.md). See [tools](./tools.md). <!-- id:zNVN4eE_ -->
