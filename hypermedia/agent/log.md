**Log** — everything that _happened_ in a thread: an append-only sequence of events (messages, tool calls, results, plan updates), each stamped with an **actor**. It's a shared workspace log, not a chat transcript — you and the agent write to the same one. <!-- id:xVgDNEcp -->
