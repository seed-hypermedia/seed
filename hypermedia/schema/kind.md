A **kind** is one of the nine basic sorts of value in the [data model](./data-model.md): `null`, `boolean`, `integer`, `float`, `string`, `bytes`, `list`, `map`, `link`. Every value is exactly one kind. For example, `"hello"` is a string and `[1, 2]` is a list. <!-- id:o8eYYCaN -->

Every type in the library is built from these nine kinds.
