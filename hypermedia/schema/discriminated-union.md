**Discriminated union** — a type that is "one of" a fixed set of variant shapes, told apart by a discriminant. In Onyx the discriminant is the `type` tag (plus "has `anyOf`" / "has `var`" / "bare `ref`"). Expressed with `anyOf`. ([the schema language](./schema-language.md)) <!-- id:Bg10mEhX -->
