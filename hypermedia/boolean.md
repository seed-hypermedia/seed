name: Boolean
summary: A true or false value.
---
The **boolean** type is a value that is either `true` or `false`. It is a [primitive](./schema/primitive.md) of the [data model](./schema/data-model.md): the ready-made schema for one [kind](./schema/kind.md) of value. The type's formal schema is attached to this page as the `schemaDefinition` in its [metadata](./metadata.md). So the app can show the schema and create values of this type. <!-- id:RgBViSE5 -->
