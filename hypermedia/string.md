name: String
summary: UTF-8 text.

The **string** type is text, such as `"hello"`. The text is stored as UTF-8. It is a [primitive](./schema/primitive.md) of the [data model](./schema/data-model.md): the ready-made schema for one [kind](./schema/kind.md) of value. The type's formal schema is attached to this page as the `schemaDefinition` in its [metadata](./metadata.md). So the app can show the schema and create values of this type. <!-- id:D-MdSYpJ -->
