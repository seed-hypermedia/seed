**write**: the mirror of [read](./read.md). It writes memory files, authored tools, and [triggers](./trigger.md) in the agent's [Space](./space.md). It publishes signed Hypermedia content, such as [documents](../protocol/documents.md), when the agent holds the **publish** [grant](./grants.md), and it uploads [files to IPFS](../protocol/files.md). See [tools](./tools.md). <!-- id:04mtKDlp -->
