---
name: Read
summary: The read verb takes one address and returns what is there, whether a memory file, a tool contract, a Hypermedia document, a web page, a conversation, or a run.
---
**read**: one verb for any address. It reads `~/memory/…`, `~/tools/…`, `~/triggers/…`, and `~/self` in the agent's [Space](./space.md). It also reads [`hm://…`](../protocol/urls.md) documents, [`ipfs://…`](../protocol/files.md) files, `https://…` pages, `activity:`, `attachment:…`, `thread:…` (bare `thread:` lists and searches the account's conversations), and `run:…`. See [tools](./tools.md) for each address. <!-- id:mR05ODxo -->
