---
name: Web Embed Block
summary: An embed of an external web page or post by https:// URL.
---
A **web embed block** embeds an external web page or post. `link` is required and is an `http(s)://` URL. The app renders known providers (such as X, Instagram and YouTube posts) as previews and everything else as a link card. The block has no text and no attributes of its own. <!-- id:YBsuig0m -->
