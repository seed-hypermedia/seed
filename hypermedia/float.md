name: Float
summary: A floating-point number.

The **float** type is a number with a fractional part, such as `1.5`. It is a floating-point number. It is a [primitive](./schema/primitive.md) of the [data model](./schema/data-model.md): the ready-made schema for one [kind](./schema/kind.md) of value. The type's formal schema is attached to this page as the `schemaDefinition` in its [metadata](./metadata.md). So the app can show the schema and create values of this type. <!-- id:q_XYaEv7 -->
