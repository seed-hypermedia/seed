A publication status: a [union](../schema/anyof.md) of three [literals](../schema/literal-schema.md), `draft`, `published` and `archived`. [article](./article.md) uses it. <!-- id:zuvxifj1 -->

This page describes the **example/status** type, one of the [example schemas](../example.md). The formal schema is attached as the `schemaDefinition` in this page's metadata, so the app can show it and create values of this type. <!-- id:rq6vJlcj -->
