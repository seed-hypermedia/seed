An open [map](../map.md) whose values are all [integers](../integer.md): `Map<Integer>`. It is the worked example in [the schema language](../schema/schema-language.md). <!-- id:w5yEMISF -->

This page describes the **example/counts** type, one of the [example schemas](../example.md). The formal schema is attached as the `schemaDefinition` in this page's metadata, so the app can show it and create values of this type. <!-- id:q7hzaQZp -->
