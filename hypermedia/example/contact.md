A required `email` and an optional `phone`. It is one of the two arms of [staff-member](./staff-member.md), which is an [employee](./employee.md) and a contact at once.

This page describes the **example/contact** type, one of the [example schemas](../example.md). The formal schema is attached as the `schemaDefinition` in this page's metadata, so the app can show it and create values of this type.
