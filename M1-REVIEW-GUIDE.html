The five scenarios ~5 min

1 · Memory through the verbs

Save a note to memory that my favorite database is SQLite, then read it back to me.
  • A Write tool row addressed ~/memory/…, then a Read row for the same path.
  • The file appears on the agent's Memory tab.

2 · Callable dispatch

Search the web for the latest Bun release and tell me the version.
  • A Call row whose subject is web_search, results rendered with links.
  • If the model guesses a wrong input shape, the row shows the tool's contract as the result and the retry succeeds — that's touch-expand, not a failure.

3 · Parallel delegation + the checklist

Research the histories of SQLite and Postgres in parallel — one child each — then write me a two-paragraph comparison.
  • One pinned checklist; two Delegate children attached under the running step.
  • The parent parks (thread stays responsive), children tick to done, parent resumes with the comparison.
  • Child titles in tool rows navigate to the child transcripts; the finished card lands in the transcript at its finish position.

4 · Script delegation

Use a script child to write three memory files — one per planet closer to the sun than Earth — each with one fact, then return the list of paths.
  • One Delegate row with a Code drawer (the script source is reviewable).
  • The script's ctx.call('write', …) effects appear in the run's Activity journal; three files land in memory.

5 · Restraint + naming

What is 12 × 9?
  • Direct answer. No delegation, no plan, no tool calls.
  • The session still gets a model-authored title (automatic — the title tool is gone).
