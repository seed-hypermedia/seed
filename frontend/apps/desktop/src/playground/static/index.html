Read the rules before you play

Reader → writer → irrevocable admin. Writer includes read. Admin includes read/write and grant/revoke. Admin chains are permanent.

Exact scope. A grant on a parent never authorizes a child. Independent valid grants combine; revoking one does not ban a key.

Sync has two sides. The reader and the hosting principal each need their own authority. Offline cached bytes cannot be recalled.

This is a draft-policy simulator. Current-standing writer rollback, native redirect/tombstone behavior and apply execution retain the limits described in the linked guides.
